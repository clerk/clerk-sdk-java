# SupportedBillingPeriods

Which billing periods this price supports.

## Example Usage

```java
import com.clerk.backend_api.models.components.SupportedBillingPeriods;

SupportedBillingPeriods value = SupportedBillingPeriods.MONTH;
```


## Values

| Name     | Value    |
| -------- | -------- |
| `MONTH`  | month    |
| `ANNUAL` | annual   |
| `BOTH`   | both     |
